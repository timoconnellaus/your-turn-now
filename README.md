# Your Turn Now

A web platformer built by friends taking turns. Each person adds one feature, then passes it on — like a story game where everyone adds a word.

## Turn 1

A red square on a flat green floor. It can move left and right and jump.

## Play

Open `index.html` in a browser. No build step, no dependencies.

Or serve it locally:

```sh
python3 -m http.server
```

Then visit http://localhost:8000.

## Controls

- Move: ← → or A D
- Jump: Space, ↑ or W

## Taking your turn

1. Pull the latest version.
2. Add one feature.
3. Add a line to the turn log below.
4. Commit, push, and tell the next person it's their turn.
